# Reinforced Visual Template Selection Guide

This guide governs the selection of visual layout templates when converting lecture transcript chunks into structured educational slides/visuals. 

---

## 1. Core Decision Rules

### Rule 1 — Prefer Simplicity
- If the lecture chunk is conversational, narrative, or doesn't have a clear structured concept/list, select **Face Only**.
- Do not force graphics where they add no direct educational value.

### Rule 2 — Match Information Density
Choose a template matching the transcript's structural organization and complexity:
- **Low Density**: Face Only, Type Template 1, Process Template 1, Differentiation Template 1, Timeline Template 1.
- **Medium Density**: Type Template 2, Process Template 2, Differentiation Template 2, Graph Templates, Hierarchy Template.
- **High Density**: Process Template 3, Timeline Template 2.

### Rule 3 — Strict Image Constraints
- Do NOT assume or generate image assets unless using **Differentiation Template 2** or **Type Template No 17** (which design-wise support image integration).
- For all other templates, output text/data content only.

### Rule 4 — Typography & Formatting Guidelines
- **Headings**: Ensure the Plate Heading is as short as possible, ALL CAPS, and does not exceed two lines (max 32 characters/letters in general).
- **Subheadings**: Must be in Title Case.
- **Description & Content Text**: Must be in Sentence case.
- **Icons**: Use line icons (avoid black fill icons). Do not omit required icons unless text length or formatting explicitly permits it.
- **Fixed Fonts**: Adhere strictly to the word count, line, and length guidelines for each template since font sizes are fixed in rendering.

## 2. Template Catalog & Mapping Criteria

### Type Templates (Categorization)
*Use when explaining categories, variants, classifications, or types.*

- **Type Template 1 (Low Density)**: Quick overview of 2-5 types. Output short labels and 1-sentence key differentiators.
  - *Guidelines*:
    - **Heading**: Max 2 lines (max 32 letters). Must be ALL CAPS.
    - **Points**: Max 3 points or sub-points.
    - **Icons**: Use line icons (no black fill); can only be replaced when using numbers/short forms.
    - **Images**: Cannot be used.
    - **Overflow**: If > 4 types, split into two plates (previous points slide out).
- **Type Template 2 (Medium/High Density)**: Detailed concept breakdowns. Output subheadings and 2-3 sentence descriptive paragraphs for each type.
  - *Guidelines*:
    - **Heading**: Max 2 lines (max 32 characters). Must be ALL CAPS.
    - **Points**: As many as needed (previous points will slide up).
    - **Icons**: Use line icons (no black fill); can only be replaced when using numbers/short forms.
    - **Images**: Cannot be used.
- **Type Template No 16**: Select when using a split-screen layout (speaker on the left, graphics on the right) and the speech involves outlining a sequence of up to four distinct steps or concepts, where each point requires a short description or a brief bulleted list.
  - *Guidelines*:
    - **Heading**: Max 2 lines. Must be ALL CAPS.
    - **Subheadings**: Optional (if omitted, content is centre aligned).
    - **Description**: Max 3 lines. Can have pointers.
    - **Icons**: Must provide line icons or use numbers.
    - **Images**: Cannot be used.
    - **Overflow**: If > 4 types, split into two plates (the first type slides out).
- **Type Template No 17**: Select when using a split-screen layout (speaker on the left, graphics on the right) and the speech introduces numbered points but requires a deep dive, an expanded detailed text explanation, or the inclusion of supporting graphics and images for a specific item on the list.
  - *Guidelines*:
    - **Heading**: Cannot be used if the heading exceeds two lines.
    - **Images**: Can have images inside the sub-text box or outside it (but only for a few seconds).
    - **Overflow**: If > 5 types, split into two plates (the first type slides out).
- **Type Template No 18**: Select when using a split-screen layout (speaker on the left, graphics on the right) and the speech involves a structured question-and-answer format, displaying specific questions (e.g., Q1, Q2) alongside one or more of their corresponding answers.
  - *Guidelines*:
    - **Questions**: Must be Sentence case. Cannot be used if the question exceeds two lines.
    - **Answers**: One question can have 2-3 answers (the box will extend to accommodate the answer).
    - **Context**: Use ONLY when both questions and answers need to be shown together.
    - **Overflow**: If > 3 questions, split into two plates (the first question slides out).
- **Type Template No 18 OG**: Select when using a full-page layout (no speaker visible) and the speech involves a structured question-and-answer format, displaying specific questions (e.g., Q1, Q2, Q3) alongside one or more of their corresponding answers.
  - *Guidelines*:
    - Same guidelines as Type Template No 18, but applied to a full-screen layout.
- **Type Template No 20**: Select when using a split-screen layout (speaker on the left, graphics on the right) and the speech outlines two distinct types, categories, or concepts, where each requires a short description or a few small bullet points.
  - *Guidelines*:
    - **Heading**: Max 2 lines (max 32 characters). Must be ALL CAPS.
    - **Content**: If description/paragraph only, centre-align it; if pointers are used, left-align them.
    - **Word Limits**: Description text cannot exceed five lines.
- **Type Template No 20 OG**: Select when using a full-page layout (no speaker visible) and the speech outlines two distinct types, categories, or concepts, side-by-side, where each requires a short description or a few small bullet points.
  - *Guidelines*:
    - Same guidelines as Type Template No 20, but applied to a full-screen layout.
- **Type Template No 21**: Select when using a split-screen layout (speaker on the left, graphics on the right) and the speech outlines three distinct types or concepts, where each requires only a subheading and a supporting graphic without additional text or bullet points.
  - *Guidelines*:
    - **Heading**: Max 2 words. Must be ALL CAPS.
    - **Subheadings**: Max 2-3 words inside the circle, Title Case.
    - **Icons**: Can be replaced with a short description (not recommended).
    - **Limitation**: Use Type Template No 21 OG if there are subpointers/sub-bullets.
- **Type Template No 21 OG**: Select when using a full-page layout (no speaker visible) and the speech outlines three distinct types or concepts represented by graphics and subheadings, where specific concepts require brief text callouts or short points branching off from them.
  - *Guidelines*:
    - Same guidelines as Type Template No 21, but allowing for brief text callouts/subpointers branching off from specific concepts.

### Process Templates (Sequences & Steps)
*Use when explaining chronological procedures, workflows, algorithms, or cause-and-effect stages.*

- **Process Template 1 (Low Density)**: Simple ordered steps. Output short labels and brief explanations.
  - *Guidelines*:
    - **Heading**: Max 2 lines (max 20 letters). Must be ALL CAPS.
    - **Pointers**: Bullets allowed, max 2 lines. Align pointers to the text.
    - **Images**: Cannot be used.
    - **Overflow**: If > 4 steps, the first step slides out.
- **Process Template 2 (Medium Density)**: Multi-stage reasoning or moderately detailed academic procedures. Output subheadings and descriptive explanations for each stage.
  - *Guidelines*:
    - **Heading**: Max 2 lines (max 32 letters). Must be ALL CAPS.
    - **Icons**: Optional (can be removed if there are > 2 pointers).
    - **Pointers**: Can be faded to fit additional points.
    - **Images**: Cannot be used.
    - **Overflow**: If > 4 steps, the first step slides out.
- **Process Template 3 (High Density)**: Deep technical or multi-level workflows. Output headers, structured details, and bullet points.
  - *Guidelines*:
    - **Heading**: Max 2 lines (max 32 letters). Must be ALL CAPS.
    - **Points**: Can have as many points/sub-points as needed (previous points will slide up).
    - **Icons & Images**: Cannot be used.
    - **Overflow**: If > 4 steps, the first step slides out.

### Differentiation Templates (Comparisons)
*Use when comparing and contrasting concepts, theories, models, or brands.*

- **Differentiation Template 1 (Low Density)**: Simple column-based text comparison points.
  - *Guidelines*:
    - **Text Length**: Each point can be a maximum of 3 lines.
    - **Icons & Images**: Cannot be used.
    - **Overflow**: If > 4 differences, split into two plates (or the first 1 or 2 points slide out).
- **Differentiation Template 2 (Medium Density - Image Supported)**: Case studies or brand comparisons with a dedicated visual area and explanation text.
  - *Guidelines*:
    - **Heading**: Main headings for the two sides should not exceed 3 words.
    - **Content**: Description and pointers (max 2-3 lines) below the image.
    - **Images**: Supports images with little text. Must be used for differences only.

### Timeline Templates (Chronological Events)
*Use when explaining history, milestones, or progression over time.*

- **Timeline Template 1 (Low Density)**: Brief milestones with simple years/timestamps and 3-5 word event summaries.
  - *Guidelines*:
    - **Pointers**: No pointers can be added.
    - **Images**: Text can be replaced with images.
    - **Timestamps**: Can have more than 5 timestamps.
- **Timeline Template 2 (Medium/High Density)**: Detailed chronological analysis. Output time markers, titles, and supporting descriptive bullet points.
  - *Guidelines*:
    - **Heading**: Cannot exceed 32 letters. Must be ALL CAPS.
    - **Points**: Can have as many points as needed. Can have more than 5 timestamps.
    - **Icons & Images**: Cannot be used.

### Hierarchy Templates (Top-Down Structure)
*Use for taxonomies, organization structures, parent-child systems, or architectures.*

- **Hierarchy Template 1**: Node-based tree structure representing hierarchy levels.
  - *Guidelines*:
    - **Heading**: Must be ALL CAPS.
    - **Text**: Must be Title Case. Points cannot be more than two lines.
    - **Points**: Can have as many points as needed.
    - **Images**: Cannot be used.

### Graph Templates (Quantitative Data)
*Use ONLY when the transcript references explicit numbers, trends, statistics, or measurable proportions.*

- **Graph Template 1 (Line Graph)**: Showing trends or performance over continuous progression (X-axis vs Y-axis).
- **Graph Template 2 (Bar Plot)**: Comparing quantities across discrete categories.
- **Graph Template 3 (Pie Chart)**: Representing proportional distributions (parts of a whole summing to 100%).
  - *Guidelines*:
    - **Heading**: Required. Must be ALL CAPS.
    - **Axis Description**: Must be Sentence case (for Line/Bar graphs).
    - **Content**: Sub-points can appear on the right side.
    - **Source**: Explicitly provide sources (e.g. "Courtesy: Company name" if print ad).

### Face Only (Default/No Graphics)
- Select when speech is narrative (storytelling, personal anecdotes), transitional ("Now let's look at..."), or lacks clear visual structures.
  - *Guidelines*: Default option when visual clarity is not improved by templates. No graphics or overlay elements.

## 3. Structured JSON Schema for Visual Output

Every selected template must populate the `visuals` JSON object according to this schema:

```json
{
  "template_name": "Must be one of: Type Template 1, Type Template 2, Type Template No 16, Type Template No 17, Type Template No 18, Type Template No 18 OG, Type Template No 20, Type Template No 20 OG, Type Template No 21, Type Template No 21 OG, Process Template 1, Process Template 2, Process Template 3, Differentiation Template 1, Differentiation Template 2, Timeline Template 1, Timeline Template 2, Hierarchy Template 1, Graph Template 1, Graph Template 2, Graph Template 3, Face Only",
  "why_chosen": "Detailed justification citing rules, information density, or transcript structural properties.",
  "graphics_required": true or false, (false ONLY for Face Only),
  "content": {
    "title": "Clear, educational heading for the visual slide",
    "items": [
      {
        "value": "Bullet point or simple list value string",
        "timestamp": 12.4
      }
    ],
    "details": [
      {
        "label": "Name of category, step, concept, timeline year, or graph category",
        "value": "Description, differentiator, event summary, or quantitative value (must match numeric data if a graph)",
        "timestamp": 25.8,
        "extra": "Optional supporting context, parent node for hierarchy, or image URL/metadata for Differentiation Template 2"
      }
    ]
  }
}
```

> [!IMPORTANT]
> **Element Timestamps**: For each element inside `items` or `details`, you MUST determine the precise `timestamp` (a float number representing seconds, e.g., 25.8) when the speaker begins discussing or explaining that specific item, step, category, or detail. Map this using the word-level or sentence-level timestamps provided in the transcript data. Do not make up timestamps outside of the chunk's time bounds.
```
